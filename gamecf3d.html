Brother In Arms 2

Requires CF3D.

APK + Data: 📥 Download

Create a folder named "data", open it, then create another folder also named "data". Finally, extract the game data into this folder.

CF3D Setting:

  • Reduce Texture Quality
  • Reduce Texture Size
  • Plugin: PowerVR

FIFA 10

Required CF3D

APK+Data: 📥 Download

Installation:
Install the APK but don't open the game yet. Create a folder named data. Inside that data folder, create another folder also named data. Put the com.eamobile.Fifa folder/file inside it.
The final path should be: /sdcard/data/data/com.eamobile.Fifa/
If you're using Chainfire 3D:

CF3D Setting:

  • Reduce Texture Quality
  • Plugin: PowerVR
