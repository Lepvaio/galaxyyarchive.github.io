How to Install Chainfire3D

  • If you haven't already, open the the Apps Page to download.
  • Download and install Chainfire3D.
  • Launch Chainfire3D. It will request Root Access. Check Always allow, then tap Grant.
  • On the main screen, tap CF3D Driver.
  • Tap Install.
  • The app will warn you that it needs to install the driver and reboot your device. Tap OK to continue.
  • After the device restarts, open Chainfire3D again.
  • Tap Install Plugins and Shaders.
  • Install each of the three plugin ZIP files, one at a time.
  • After each installation, tap OK and wait for it to finish before installing the next one.
  • Once all plugins have been installed, press the Back button to return to the main screen.
  • Tap Default OpenGL
    • Settings.
  • Tap Use Plugin.
  • Choose the plugin that matches the game you want to run:
  • Nvidia
  • Qualcomm
  • PowerVR
  • Exit the application and restart your device.
  • You're now ready to play games using Chainfire3D. Enjoy!
